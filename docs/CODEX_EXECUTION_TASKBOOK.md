## 2. 用户、痛点与目标

- 用户：教师、教研组长、教学主管、课堂观察员
- 痛点：课堂观察容易停留在“互动好/气氛活跃”等主观描述，缺少对提问层级、等待时间、反馈方式和学生参与结构的证据分析。
- 目标：基于课堂转录或观察记录分析教师提问、学生回应、追问、等待时间和反馈质量，输出可操作的改进建议。

| `learning_objectives` | 课堂目标 | array | 是 |
| `class_type` | 班型 | string | 是 |
| `observation_focus` | 观察重点 | array | 否 |
| `consent_status` | 录制与使用授权状态 | string | 是 |

## 4. 工作流

1. 核对转录质量
2. 切分教学片段
3. 编码提问与反馈
4. 统计参与和等待时间
5. 提炼模式
6. 给出保留点与改进实验

## 6. 核心成果

- `课堂对话分析表`

## 7. 差异化与排重

- 与现有产品：课堂观察量表提供观察工具；本产品分析真实课堂对话内容与互动过程，输出证据化诊断。
- 排重检查：部分重叠；共享教师改进目标，但本产品输入课堂转录/对话，输出问答编码和片段证据。
- 独立理由：无需量表或教师发展 Agent 也可独立完成单节课分析。
