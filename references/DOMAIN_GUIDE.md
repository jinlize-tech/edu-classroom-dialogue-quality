# 课堂对话与提问质量分析领域指南

## 业务问题

课堂观察容易停留在“互动好/气氛活跃”等主观描述，缺少对提问层级、等待时间、反馈方式和学生参与结构的证据分析。

## 产品解决方案

基于课堂转录或观察记录分析教师提问、学生回应、追问、等待时间和反馈质量，输出可操作的改进建议。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `transcript_redacted` | 脱敏课堂转录 | 是 | 以学生编号替代真实身份 |
| `grade_and_subject` | 年级与学科 | 是 | 用于专业规则校准 |
| `learning_objectives` | 课堂目标 | 是 | 用于判断提问与目标对齐 |
| `class_type` | 班型 | 是 | 大班、小班、一对一或线上 |
| `observation_focus` | 观察重点 | 否 | 例如高阶层提问、候答时间或反馈 |
| `consent_status` | 录制与使用授权状态 | 是 | 未获授权时应停止处理真实录音 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

转写误差会影响结论；不得把指标当教师绩效唯一依据；涉及课堂录音需授权、脱敏和最小化。
